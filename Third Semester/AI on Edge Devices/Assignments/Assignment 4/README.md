## Run notes and time (Apple Silicon, MPS)

| Task | What runs | Approx. time |
|---|---|---|
| 1 | B7 teacher pass + two B0 students (5 epochs) + T1.2/T1.3 fine-tuning (2 epochs each) | ~20–30 min |
| 2 | Teacher generates 1,000 solutions (cached in `teacher_raw.jsonl`, resumable) → LoRA training → evaluation | ~2–3 h (mostly teacher generation) |
| 3 | DARTS search (3 epochs) + discrete model (5 epochs) | ~1 min |
| 4 | Supernet (5 epochs) + 12 adaptations + 2 from-scratch runs | ~2 min |
| 5 | Benchmark lookups only (no training) | seconds |

- **Task 2 memory:** LoRA training uses micro-batch 1 with 8 gradient-accumulation steps (effective batch 8). Larger micro-batches caused MPS out-of-memory and GPU time-out errors on this machine.
- **Task 2 synthetic questions:** `task2_outputs/synthetic_raw.json` was generated with Claude (prompt in the report, T2.1) and is checked automatically by the notebook.
- **Seeds:** 42 for Tasks 1–4; 0, 1, 2 for Task 5.
