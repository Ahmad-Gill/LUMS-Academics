01 / THE MISSING CAPABILITY

Learning is possible without nonlinearity. Context-dependent behavior needs more.

A linear model can learn excellent weights. Its limitation is the kind of rule those weights can express: each input contributes a fixed amount to the score.

z = w₁x₁ + w₂x₂ + … + wdxd + b
a = φ(z)

The weighted sum asks, “How much evidence is present along this learned direction?” The activation φ decides how that evidence is converted into a feature for later computation. With a bias, the first operation is technically affine; we will use “linear layer” in the usual neural-network sense.

For a linear score, increasing x₁ by one always changes z by w₁, holding the other inputs fixed. The change does not depend on x₂. This is a good model when contributions are additive. It is restrictive when one input changes the interpretation of another.

f(x + Δ) − f(x) = WΔ
Same change Δ → same change in output, wherever x starts.

In a nonlinear network, that change can depend on where you are in the input space. “More heat” can help a cold room but hurt an already hot room. “Not” can reverse the sentiment carried by the word it modifies. The point is not that the curve looks rounded: even a sharp corner can change the rule.

Why depth alone does not fix this

h = W₁x + b₁
y = W₂h + b₂
= (W₂W₁)x + (W₂b₁ + b₂)

Two affine layers collapse into one. The same is true of any stack containing only affine operations. Learning may behave differently because the parameters are factorized, and a narrow layer may restrict rank, but the input–output mapping remains affine.

Insert a nonlinearity and the collapse generally fails. For ReLU, which passes positive values and sets negative ones to zero, the active units depend on x. Within one fixed activation region a network acts affinely; across regions it uses different effective matrices.

h = ReLU(W₁x + b₁)
Within one region: y = W₂D(W₁x + b₁) + b₂
D = diagonal matrix of 0/1 activation switches

The important fact is that D can change with the input. Training learns both the local calculations and where the network switches between them.

Do not confuse the score and its final output. Logistic regression uses a nonlinear sigmoid on its score, yet thresholding its probability still gives a linear decision boundary. A monotonic output squashing function alone does not supply the learned hidden features needed for problems such as XOR.
02 / ONE EXAMPLE, TWO REPRESENTATIONS

“Good,” “bad,” and the meaning of “not”

Begin with a deliberately simplified sentiment task. Treat “good” as +1, “bad” as −1, “not good” as −1, and “not bad” as +1. Real language is subtler: “not bad” need not mean “excellent,” and negation has scope. These four cases isolate the computational issue.

Version A: word indicators

Let g, b, and n be binary indicators for the presence of “good,” “bad,” and “not.” A linear score is s = wgg + wbb + wnn + c.

To turn “good” from positive to negative, adding “not” must decrease the score, so wn must be negative. To turn “bad” from negative to positive, adding “not” must increase it, so the same wn must be positive. Neither a different bias nor additional linear layers resolves this contradiction.

hng = ReLU(n + g − 1)
hnb = ReLU(n + b − 1)
s = g − b − 2hng + 2hnb

Each hidden feature now detects a combination. With binary inputs, hng is 1 only when both “not” and “good” occur; otherwise it is 0. The last layer still adds fixed weighted features, but the features themselves encode interactions.

Final score: +1 → positive in the toy task.

Your vector objection is correct—and reveals the essential distinction

Suppose “good” is a sentiment vector v and “bad” is −v. Negation could apply the very same transformation to both: multiply by −I. This operation is linear in the sentiment vector. But deciding whether to apply it based on a second input is not jointly linear.

Let v be the sentiment representation and n ∈ {0,1} indicate negation. The desired mapping is:

F(v,n) = (1 − 2n)v = v − 2nv

For a fixed n, this is linear in v. As a function of the combined input (v,n), the term nv is an interaction. A plain affine layer on their concatenation can only give Av + un + c: n adds a fixed vector u, rather than changing the matrix applied to v.

Translation

v → v + u

To turn v into −v requires u = −2v. To turn −v into v requires u = +2v. One fixed translation cannot do both for nonzero v.

Conditional transformation

v → (1 − 2n)v

n chooses identity or negation. Each branch is linear; selecting a branch using the input adds the needed interaction.

Where did the extra power enter? If you hand-engineer nv, a phrase embedding, or a “not good” indicator, a linear classifier on those features may suffice. You have already performed a nonlinear transformation of the original inputs. Neural networks can learn such features instead of requiring you to enumerate them.

If we remove both ReLUs from the constructed detector network, its score becomes g − b − 2(n + g − 1) + 2(n + b − 1) = −g + b. Negation disappears entirely. The clipping was doing real computational work.

03 / TWO MORE WAYS TO SEE IT

A relation between inputs—and a bounded region

Example 2: XOR means “different”

Imagine an alarm that should sound when two binary sensors disagree. Either sensor alone activates the alarm; both together cancel it. A positive weight on each sensor can reward each “on,” but then both “on” receives even more reward.

No single straight line separates the two “alarm” corners from the two “quiet” corners.

h₁ = ReLU(x₁ − x₂)
h₂ = ReLU(x₂ − x₁)
y = h₁ + h₂ = |x₁ − x₂|

One unit detects “sensor 1 exceeds sensor 2”; the other detects the reverse. Their sum is exactly XOR on binary inputs.

The combination works because the units are selective. Without ReLU, the two differences would sum to zero for every input.

A short proof that a linear score cannot classify XOR

Let the positive class have score > 0 and the negative class have score < 0. Quiet at (0,0) requires c < 0; quiet at (1,1) requires w₁ + w₂ + c < 0. Alarm at (1,0) and (0,1) requires w₁ + c > 0 and w₂ + c > 0. Adding the last two inequalities gives w₁ + w₂ + 2c > 0. Adding the first two gives the same expression < 0: a contradiction.

Example 3: a room can be too cold or too hot

In this toy model, comfort rises from zero at 18°C to a peak at 22°C, then falls to zero at 26°C. A single linear score cannot first rise and then fall. Three ReLU “hinges” create a triangular comfort function:

C(T) = [ReLU(T − 18) − 2ReLU(T − 22)
+ ReLU(T − 26)] / 4
C(23) = 0.75. Hinge outputs: 5, 1, 0.

Each threshold changes the slope. At 18°C, the first hinge starts an upward slope. At 22°C, the second contributes twice the downward slope, reversing the trend. At 26°C, the third flattens it again. A threshold on C(T) can classify a bounded interval as comfortable.

Nonlinearity lets a network construct useful regions and interactions. It is not restricted to “curved boundaries,” and it need not be smooth. Piecewise linear components already create rich behavior.
04 / EXPRESSIVENESS IS ONLY HALF THE STORY

What makes a nonlinearity useful for learning?

A function may enable the desired input–output mapping yet make it difficult to find with gradient descent. Separate capacity—can the network represent the rule?—from optimization—can training discover useful parameters? Neither guarantees generalization to unseen data.

∂L/∂wᵢ = (∂L/∂a) · φ′(z) · xᵢ

The activation derivative scales the training signal entering a neuron’s weights. A tiny derivative attenuates that signal; zero blocks that path for that example. Across layers, the chain rule multiplies activation derivatives and weight matrices. This is why depth makes gradient behavior important.

Desirable propertyWhy it mattersWhat is not required
Non-affine behavior in the operating rangeEnables different responses in different input regions.Not every layer must contain a nonlinear activation; the output may be linear.
Usable derivatives on enough training inputsAllows weights and biases to receive informative updates.The derivative need not be positive or nonzero everywhere.
Manageable signal and gradient scaleAvoids recurrent collapse or explosion through depth.The output need not be bounded, and one activation cannot ensure stability alone.
Compatibility with gradient trainingDerivative-based optimization should have a useful local signal.Perfect smoothness is unnecessary: ReLU is not differentiable at zero.
Acceptable computational costActivation and projection costs accumulate across large networks.A mathematically elegant function is not automatically best in practice.

A hard step function is expressive as a threshold but has zero derivative almost everywhere. Ordinary backpropagation therefore cannot efficiently move its threshold through the usual derivative path. Specialized estimators can work around this, but it is an inconvenient starting point.

Conversely, a nonlinearity can be theoretically useful yet mostly operate in an almost linear or saturated range on the actual data. Initialization, normalization, residual connections, learning rate, width, and the input distribution all affect the outcome. The activation is one part of that system. [1]

“Any nonlinearity works” is too broad. A constant function destroys information. A square is nonlinear and useful, but a fixed-depth network built only from polynomial activations has a bounded polynomial degree. Standard universal-approximation results have conditions on activation families, width, domain, and error; they are not promises that any nonlinear choice trains well.
05 / A SEQUENCE OF DESIGN QUESTIONS

From a soft detector to a smooth, unbounded signal

This is a pedagogical progression, not a strict historical succession or a ranking. These functions coexist. The question at each step is which limitation we are addressing and what tradeoff we introduce.

Keep the same hidden unit in mind: z is a learned score for a pattern such as a negated positive expression. Its activation is an internal feature, not necessarily a probability, sentiment label, or interpretable concept. We use a named detector to make the computation visible.

1. Sigmoid: a soft yes/no detector

σ(z) = 1 / (1 + e−z)
σ′(z) = σ(z)[1 − σ(z)]

Sigmoid maps any score to (0,1). Negative evidence produces a small output; positive evidence produces a large one. You can turn the binary co-occurrence detector into a soft one using σ(k(n + g − 1.5)). When both indicators are 1, the argument is positive; with only one or neither, it is negative. Increasing k sharpens the distinction.

This gives a natural “how strongly should this detector fire?” signal. But near either extreme, large changes in z cause little change in the output. The local slope becomes tiny. Sharp detectors therefore risk being difficult to adjust when their inputs are far from the transition.

The maximum derivative is ¼. In a simplified chain with unit weights, ten such maximum derivatives multiply to (¼)10 ≈ 9.54 × 10−7. This isolates one source of attenuation; actual networks also contain weight matrices, alternate paths, and normalization, so it is not a universal bound on their gradients.

A needed correction to the spoken explanation: a confidently wrong sigmoid output trained with binary cross-entropy need not have a tiny logit gradient: ∂L/∂z = σ(z) − y. The saturation concern here chiefly concerns hidden sigmoid units and repeated derivatives, or other loss combinations. Sigmoid remains useful for binary probabilities and bounded gates.

2. Tanh: center the signal, retain saturation

tanh(z) = 2σ(2z) − 1
tanh′(z) = 1 − tanh²(z)

Tanh gives a signed response in (−1,1) and passes through zero. Around zero its slope is 1. A detector can now send a negative, near-zero, or positive signal. With a roughly symmetric pre-activation distribution, its output is more naturally centered than sigmoid’s positive-only output.

This can make optimization friendlier, but it does not ensure zero mean on arbitrary data. Nor does a negative hidden value automatically mean negative sentiment: its downstream weight decides its contribution. Tanh still becomes flat at both extremes. It remains useful when a bounded signed state is wanted, including recurrent-network components.

3. ReLU: remove the positive ceiling

ReLU(z) = max(0,z)
ReLU′(z) = 0 for z < 0; 1 for z > 0

For our detector, “no match” produces silence, while a positive match passes its magnitude onward. There is no upper saturation. Strong positive evidence remains distinguishable, and the activation itself does not attenuate the gradient on the active branch. Rectifier networks also produce exact zero activations. [2]

Why ignore negative inputs?

Because clipping one side is a simple way to create a selective, non-affine feature. Zero is a threshold in the learned coordinate z, not a claim that negative raw data is irrelevant. The bias shifts the threshold and the weights choose the direction. “Below zero” means this particular feature is inactive.

The network can represent the opposite feature with ReLU(−z), and z = ReLU(z) − ReLU(−z). A positive activation can also make a negative contribution through a negative output weight. Thus ReLU does not prevent a network from representing negative values or negative relationships. It does discard information at an individual unit, so width and representation design matter.

The price: a unit can stop receiving updates

If a unit has z < 0 for every training example, its incoming weights and bias receive zero data-loss gradient through this ReLU. That is the dead-unit problem. Being off for one example is normal; being off for all relevant examples is the danger. Changes to upstream features, optimizer state, or other effects may revive it, so “permanently dead under all circumstances” would be too strong.

ReLU is inexpensive and a useful baseline. Its corner at zero is usually handled with a chosen derivative value, commonly zero. Smoothness everywhere is not necessary for successful training.

4. Leaky ReLU: keep a small route for correction

LeakyReLU(z) = z if z ≥ 0; αz otherwise
Typical design choice: a small fixed α > 0

Our detector is no longer exactly silent on the negative side. It emits a small negative response and receives a gradient scaled by α. A badly placed detector can still adjust through those examples. The cost is losing exact zeros and allowing negative signals to propagate. A very small α can still attenuate gradients substantially.

5. PReLU: learn the negative slope

Parametric ReLU uses the same piecewise formula but learns α, often per channel. The model can choose how much negative response to retain rather than using one manually chosen slope. It adds parameters and another degree of freedom to optimize. If α becomes 1, the unit is simply linear; learned flexibility is not a guarantee of useful nonlinearity. PReLU and rectifier-aware initialization were studied together by He and colleagues. [3]

6. ELU: retain negative outputs, but bound their magnitude

ELU(z) = z if z > 0; α(ez − 1) otherwise

ELU bends toward −α on its negative side while remaining linear on the positive side. It can provide negative activations without the unbounded negative tail of Leaky ReLU. The negative derivative αez becomes small far to the left, so this is a tradeoff rather than a cure for saturation. At α = 1 the first derivative joins smoothly at zero; for arbitrary α it need not. [4]

Softplus offers another branch of the design space: log(1 + ez) is a smooth approximation to ReLU with derivative σ(z). It has no exact zeros and tends to a flat negative tail. SELU combines a scaled ELU-like function with particular initialization and architectural conditions to encourage self-normalizing behavior. Neither is an obligatory step toward gated Transformers.

7. GELU: weight the score with a smooth self-gate

GELU(z) = z Φ(z)
GELU′(z) = Φ(z) + zϕ(z)

Here Φ is the standard normal cumulative distribution function and ϕ its density. The input is multiplied by a smooth weight between 0 and 1. Large positive scores pass almost unchanged; large negative scores approach zero from below. Modestly negative scores can produce small negative outputs. The usual activation is deterministic; the CDF does not mean it samples a random mask. [5]

One intuition is a detector that modulates evidence continuously instead of applying an abrupt cutoff. However, its response is not simply a monotonic soft on/off switch: GELU dips below zero, and its derivative can be negative. Hidden outputs are not calibrated confidence values. The positive side avoids sigmoid’s ceiling; the far negative tail can still have tiny gradients.

8. SiLU / Swish: the same self-gating idea with a sigmoid

SiLU(z) = zσ(z)
SiLU′(z) = σ(z) + zσ(z)[1 − σ(z)]
Swishβ(z) = zσ(βz); SiLU = Swish1

SiLU multiplies the score by a sigmoid of that same score. Unlike sigmoid alone, it is unbounded above because the multiplier approaches 1 as z increases. It has a smooth negative dip and a negative tail that approaches zero. The SiLU and Swish studies examine this family in different settings. [6] [7]

GELU and SiLU offer related behaviors with different gate shapes. Neither uniformly dominates the other. Smoothness can help optimization, but it is not by itself proof of better accuracy or healthier gradients. Their derivatives can exceed 1 or become negative, and the negative tail still attenuates the signal.

The next change is architectural. So far we changed how a single score z is transformed. GLU introduces two learned projections and multiplies them. SwiGLU applies SiLU to one of those branches.

07 / FROM SELF-GATING TO TWO LEARNED BRANCHES

GLU, GEGLU, and SwiGLU

In SiLU, one scalar z supplies both the value and the argument of its gate. A gated linear unit separates those roles. One learned projection supplies a value a; another supplies a control score q. Both are computed from the input representation x.

a = Wvx + bv   (value branch)
q = Wgx + bg   (gate branch)
h = a ⊙ σ(q)   (GLU)

The symbol ⊙ means elementwise multiplication. In each hidden coordinate, a is multiplied by its matching gate. The “value” branch is an FFN projection, not necessarily the V projection from attention.

Input xCurrent representation
Two projectionsa = Wvx + bv
q = Wgx + bg
Multiplyh = a ⊙ φ(q)
Mix outputsy = Woh + bo

GLUs were developed for gated convolutional language models. The bounded sigmoid branch controls how much of a linear value signal passes through. Later GLU variants change that branch’s activation. [8]

Return to negation: separate “what” from “when”

Our desired sentiment rule was F(v,n) = v − 2nv. Interpret v as a baseline and −2v as a proposed correction. Multiplying the correction by n applies it only under negation.

baseline + correction × applicability
v + (−2v) × n

This exposes the reason gating is natural: the gate can respond to context while the value carries the quantity to modify. With a sigmoid gate G(n) = σ(k(n − ½)), the expression v − 2vG(n) approaches the exact rule as k grows. At finite k, G is not exactly 0 or 1.

In the construction, a positive sigmoid gate does not itself reverse the sign of its value branch. The negative correction, combined with the baseline, reverses sentiment. A real model need not allocate a clean “negation gate”; these roles are an explanatory decomposition.

For SwiGLU, be careful about the nested expression: h = a ⊙ [q ⊙ σ(q)]. The inner sigmoid lies in (0,1), but the complete multiplier qσ(q) does not. Calling it a gate is an architectural metaphor, not a probability interpretation.

Why multiplication matters mathematically

Even without sigmoid or SiLU, multiplying two learned linear projections creates interactions. If a = uᵀx and q = wᵀx, their product is:

aq = (Σᵢ uᵢxᵢ)(Σⱼ wⱼxⱼ)
= Σᵢ Σⱼ uᵢwⱼxᵢxⱼ

The terms xᵢxⱼ are products of input features. The overall mapping is quadratic in x, even though each branch is linear. The “linear” in GLU does not mean the full gated unit is a linear function.

What happens to the gradients?

h = a φ(q)
∂h/∂a = φ(q)
∂h/∂q = a φ′(q)

The gate controls the gradient to the value branch; the value scales the gradient to the gate branch. This is a flexible interaction, but not a guarantee of gradient flow. A near-zero multiplier can suppress one path, a small derivative can suppress the other, and large values can amplify gradients. Residual paths, normalization, initialization, and optimization remain important.

Why use these variants? In Shazeer’s matched-parameter and matched-computation Transformer experiments, GEGLU and SwiGLU improved over the ReLU/GELU baselines in the tested setup. This is empirical evidence for the design, not a theorem that either wins for every task or model. [9]

Where does “not” enter a token’s FFN?

A standard Transformer FFN operates separately on each token’s current vector, using shared parameters across positions. It does not directly scan neighboring words. Attention and earlier computation can place information about “not” into the representation of “good”; the FFN can then transform the contextual features within that vector.

The toy indicator example assumed the relevant evidence was already available in its input. It should not be read as a claim that an isolated tokenwise FFN can discover absent context. Nor does a nonlinear activation alone recover word order from a bag-of-words input that discarded it.

Scope of the “linear layers collapse” argument: it applies to a stack containing only affine operations. A Transformer also has softmax attention, input-dependent products, and normalization. Removing the FFN activation does not make the entire Transformer linear.

Why not keep adding complexity forever?

The objective is useful performance per unit of compute and data, not maximal mathematical complexity. Better function families may help optimization or make useful interactions easier to represent. They also change memory needs, hardware efficiency, stability, and tuning requirements. Evaluate the complete architecture with an appropriate baseline.

Checks for understanding

1. Is multiplying by −1 nonlinear?

No. It is linear. The mapping (v,n) → (1 − 2n)v is not jointly linear because the input n selects which transformation acts on v.

2. If ReLU is linear on both sides, where is the nonlinearity?

The slopes differ across the threshold: 0 on one side, 1 on the other. There is no single affine rule valid over the whole domain. If every unit keeps the same active/inactive status throughout a region, the network is affine within that region.

3. Does a negative ReLU input contain useless information?

No. This unit discards it by design. Other units, including one with the opposite projection, can retain it. ReLU creates selective features; it does not establish a universal meaning for a negative number.

4. Could a linear classifier solve the sentiment task?

Yes, if its supplied features already include the relevant interactions, such as “not good,” “not bad,” or nv. The impossibility applies to a linear mapping of the original additive indicators or concatenated inputs, not to every possible representation.

5. Does SwiGLU mean SiLU applied twice?

No. A typical SwiGLU hidden feature is (Wᵥx) ⊙ SiLU(Wɡx). Two separately learned projections supply value and gate score, followed by an output projection in the FFN.

6. Can a GLU be nonlinear without a nonlinear branch activation?

Yes. Multiplying two input-dependent linear projections introduces products of input coordinates. This is often called a bilinear variant; as a function of their shared input, it is quadratic.

7. Does switching activation automatically improve a trained model?

No. The learned weights are adapted to the existing function. An architecture comparison typically requires appropriate training or fine-tuning and matched resource budgets. A direct substitution changes the computation.

The central idea: a network becomes more expressive when it can build input-dependent interactions and different responses across regions. A good activation makes those responses practical to learn. Gated FFNs make interactions explicit by letting one learned projection modulate another.
